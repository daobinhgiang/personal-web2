## Prerequisites

Before you begin, make sure you have:

1. **MongoDB Account** - Sign up at [mongodb.com](https://www.mongodb.com/)
2. **MongoDB Atlas Cluster** - Create a free cluster (M0 tier is sufficient)
3. **Node.js** installed (v18 or higher recommended)
4. **Next.js project** set up and running

## Environment Setup

### Step 1: Get Your MongoDB Connection String

1. Log in to [MongoDB Atlas](https://cloud.mongodb.com/)
2. Click **"Connect"** on your cluster
3. Choose **"Connect your application"**
4. Copy the connection string (it should look like: `mongodb+srv://username:password@cluster.mongodb.net/`)
5. Replace `<password>` with your actual database password
6. Replace `<dbname>` with your desired database name (e.g., `personal-web`)

### Step 2: Configure Environment Variables

Create or update your `.env` file in the project root:

```env
# MongoDB Configuration
MONGO_URI=mongodb+srv://username:password@cluster.mongodb.net/personal-web?retryWrites=true&w=majority

# Base URL (for production deployments)
NEXT_PUBLIC_BASE_URL=http://localhost:3000
```

**Important:** 
- Never commit your `.env` file to version control
- Update `NEXT_PUBLIC_BASE_URL` to your production URL when deploying

### Step 3: Verify MongoDB Connection

Test your database connection:

```bash
npm run dev
```

Visit: `http://localhost:3000/api/test-db`

You should see a success message if the connection is working.

## Database Schema

### Posts Collection

The `posts` collection stores all blog posts with the following structure:

```typescript
{
  _id: ObjectId,           // Auto-generated by MongoDB
  title: string,           // Post title (required)
  content: string,         // Post content/body (required)
  excerpt: string,         // Short summary (optional)
  author: string,          // Author name (default: "Anonymous")
  createdAt: Date,         // Creation timestamp
  updatedAt: Date          // Last update timestamp
}
```

**Example Document:**

```json
{
  "_id": "65abc123def456789012345",
  "title": "My First Blog Post",
  "content": "This is the full content of my blog post...",
  "excerpt": "A brief summary of the post",
  "author": "John Doe",
  "createdAt": "2026-01-25T10:30:00.000Z",
  "updatedAt": "2026-01-25T10:30:00.000Z"
}
```

## API Endpoints

### 1. Get All Posts

**GET** `/api/posts`

Retrieves all blog posts, sorted by creation date (newest first).

**Response:**
```json
{
  "success": true,
  "posts": [
    {
      "_id": "65abc123...",
      "title": "Post Title",
      "content": "Post content...",
      "excerpt": "Post excerpt",
      "author": "Author Name",
      "createdAt": "2026-01-25T10:30:00.000Z",
      "updatedAt": "2026-01-25T10:30:00.000Z"
    }
  ]
}
```

**Usage Example:**
```javascript
const response = await fetch('/api/posts');
const data = await response.json();
console.log(data.posts);
```

---

### 2. Create New Post

**POST** `/api/posts`

Creates a new blog post.

**Request Body:**
```json
{
  "title": "My New Post",
  "content": "The full content of the post...",
  "excerpt": "Optional short summary",
  "author": "Your Name"
}
```

**Response:**
```json
{
  "success": true,
  "postId": "65abc123..."
}
```

**Usage Example:**
```javascript
const response = await fetch('/api/posts', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    title: 'My New Post',
    content: 'Post content here...',
    excerpt: 'Brief summary',
    author: 'John Doe'
  })
});
const data = await response.json();
console.log('New post ID:', data.postId);
```

---

### 3. Get Single Post

**GET** `/api/posts/[id]`

Retrieves a specific post by its ID.

**Parameters:**
- `id` - MongoDB ObjectId of the post

**Response:**
```json
{
  "success": true,
  "post": {
    "_id": "65abc123...",
    "title": "Post Title",
    "content": "Post content...",
    "excerpt": "Post excerpt",
    "author": "Author Name",
    "createdAt": "2026-01-25T10:30:00.000Z",
    "updatedAt": "2026-01-25T10:30:00.000Z"
  }
}
```

**Usage Example:**
```javascript
const postId = '65abc123...';
const response = await fetch(`/api/posts/${postId}`);
const data = await response.json();
console.log(data.post);
```

---

### 4. Update Post

**PUT** `/api/posts/[id]`

Updates an existing post.

**Parameters:**
- `id` - MongoDB ObjectId of the post

**Request Body:**
```json
{
  "title": "Updated Title",
  "content": "Updated content...",
  "excerpt": "Updated excerpt"
}
```

**Response:**
```json
{
  "success": true,
  "modified": true
}
```

**Usage Example:**
```javascript
const postId = '65abc123...';
const response = await fetch(`/api/posts/${postId}`, {
  method: 'PUT',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    title: 'Updated Title',
    content: 'Updated content...'
  })
});
const data = await response.json();
console.log('Modified:', data.modified);
```

---

### 5. Delete Post

**DELETE** `/api/posts/[id]`

Deletes a specific post.

**Parameters:**
- `id` - MongoDB ObjectId of the post

**Response:**
```json
{
  "success": true
}
```

**Usage Example:**
```javascript
const postId = '65abc123...';
const response = await fetch(`/api/posts/${postId}`, {
  method: 'DELETE'
});
const data = await response.json();
console.log('Deleted:', data.success);
```

---

### 6. Batch Delete Posts

**POST** `/api/posts/batch-delete`

Deletes multiple posts in a single request (more efficient than deleting one by one).

**Request Body:**
```json
{
  "postIds": ["65abc123...", "65def456...", "65ghi789..."]
}
```

**Response:**
```json
{
  "success": true,
  "deletedCount": 3,
  "requestedCount": 3
}
```

**Usage Example:**
```javascript
const postIds = ['65abc123...', '65def456...', '65ghi789...'];
const response = await fetch('/api/posts/batch-delete', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ postIds })
});
const data = await response.json();
console.log(`Deleted ${data.deletedCount} out of ${data.requestedCount} posts`);
```

## Using the Admin Dashboard

### Accessing the Dashboard

1. Navigate to: `http://localhost:3000/adminlogin`
2. Log in with your admin credentials
3. You'll be redirected to: `http://localhost:3000/admin`

### Creating Posts

**Method 1: From Dashboard Header**
1. Click the **"+ New Post"** button in the Recent Posts section
2. Fill in the post details:
   - **Title** (required)
   - **Excerpt** (optional - used for previews)
   - **Content** (required - supports markdown)
3. Click **"Publish Post"** to save

**Method 2: From Quick Actions**
1. Click **"📝 Create New Post"** in the Quick Actions sidebar
2. Follow the same steps as Method 1

**Tips:**
- Write a compelling excerpt to attract readers
- Use clear, descriptive titles
- Break up long paragraphs for readability
- The content field supports markdown formatting

### Viewing Posts

**From Dashboard:**
- All posts are listed in the "Recent Posts" section
- Click **"View"** on any post to see it on the public blog

**From Public Pages:**
- Home page: Shows 3 most recent posts
- Blog page: Shows all posts
- Individual post: Click on any post title

### Deleting Posts

**Single Post Deletion:**
1. Find the post in the "Recent Posts" section
2. Click the **"Delete"** button next to the post
3. Confirm the deletion

**Bulk Deletion:**
1. Click **"Delete Posts"** button in the Recent Posts header
2. Checkboxes will appear next to each post
3. Select the posts you want to delete
4. Use **"Select All"** to select all posts at once
5. Click **"Delete (n)"** where n is the number of selected posts
6. Confirm the deletion
7. Click **"Cancel"** to exit delete mode without deleting

## Troubleshooting

### Connection Issues

**Error: "Cannot connect to MongoDB"**

Solutions:
1. Check your `MONGO_URI` in `.env` file
2. Verify your IP address is whitelisted in MongoDB Atlas:
   - Go to Network Access in Atlas
   - Add your IP or use `0.0.0.0/0` for all IPs (not recommended for production)
3. Ensure your database user has correct permissions
4. Check if your password contains special characters - they may need URL encoding

### No Posts Showing

**Problem:** Dashboard or blog page shows "No posts yet"

Solutions:
1. Verify you've created posts from the admin dashboard
2. Check browser console for API errors
3. Test the API directly: `http://localhost:3000/api/posts`
4. Ensure MongoDB connection is working: `http://localhost:3000/api/test-db`

### Authentication Issues

**Problem:** Can't access admin dashboard

Solutions:
1. Make sure you've created an admin account
2. Clear browser cookies and try logging in again
3. Check that authentication cookies are enabled
4. Verify the session API is working: `http://localhost:3000/api/auth/session`

### API Errors

**Error: "Invalid post ID"**
- The post ID must be a valid MongoDB ObjectId (24-character hex string)
- Check that you're passing the correct `_id` from the database

**Error: "Title and content are required"**
- Both `title` and `content` fields are required when creating posts
- Make sure you're sending valid JSON in the request body

**Error: "Post not found"**
- The post may have been deleted
- Verify the post ID exists in your database

## Best Practices

### Security

1. **Never expose credentials**
   - Keep `.env` file out of version control
   - Use `.gitignore` to exclude `.env`
   - Rotate passwords regularly

2. **Production Deployment**
   - Use environment-specific connection strings
   - Enable MongoDB authentication
   - Use IP whitelisting in production
   - Implement rate limiting on API endpoints

3. **Authentication**
   - Keep admin dashboard protected
   - Use strong passwords
   - Consider adding two-factor authentication

### Performance

1. **Caching**
   - Consider implementing Redis for caching frequently accessed posts
   - Use Next.js ISR (Incremental Static Regeneration) for blog pages

2. **Pagination**
   - For blogs with many posts, implement pagination
   - Limit the number of posts fetched per request

3. **Indexing**
   - Create indexes on frequently queried fields (e.g., `createdAt`)
   - Monitor query performance in MongoDB Atlas

### Content Management

1. **Backup Regularly**
   - Set up automated backups in MongoDB Atlas
   - Export important posts regularly

2. **Version Control**
   - Consider implementing post versioning
   - Keep drafts separate from published posts

3. **Rich Content**
   - Use markdown for formatting
   - Consider adding image upload functionality
   - Implement code syntax highlighting
